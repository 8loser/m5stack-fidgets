# m5stack-fidgets

M5Stack Core2 上的物理模擬小玩具合集:傾斜裝置給重力、點螢幕互動,撞擊有合成的鋼琴音與震動。

## 遊戲

| # | 名稱 | 玩法 |
|---|---|---|
| 1 | 彈珠 | 18 顆球互撞、殘影;手指排斥球;搖一下裝置全部散開 |
| 2 | 高爾頓板 | 自動落球堆成長條圖;點一下在該處丟 5 顆 |
| 3 | 色層擴張 | 旋轉的 6 色環,球撞到哪色那色往外長一層,先長滿的贏後整環脫落 |
| 4 | 井字 | 旋轉的 3x3 箱,牆和 O/X 都會反彈;每 2 秒在離球最近的空格蓋記號 |
| 5 | 切割 | 多邊形掃過中央小球就被切開,片片慢慢長大,塞滿後炸開 |
| 6 | 向心加速 | 同心環各有旋轉的缺口,球穿過缺口就往內一層並加速,碰到中心炸開 |
| 7 | 三角形溢出 | 三角形場地右邊有缺口,每逃出一個小三角形就生 3 個,直到塞滿 |
| 8 | 合成圓 | 圓形場地掉下多邊形,相同的碰到就合成邊數多一級的,直到生出圓 |
| 9 | 方塊變大 | 方塊每撞牆就長大,填滿場地後場地放大一級 |
| 10 | 氣球與尖刺 | 氣球每彈一次就充大,碰到邊上的尖刺才會破,破一個生兩個 |
| 11 | 細胞分裂 | 紅藍細胞不斷分裂互相推擠,塞滿時多的那隊贏 |
| 12 | 塗滿圓 | 粗球走過留下顏色,每撞牆換色,直到整個圓塗滿 |
| 13 | 逃脫加速 | 從中心穿過各環缺口往外逃,每逃出一環就加速,逃出全部進下一回合 |
| 14 | 踩拍子 | 球在琴鍵上一格格跳,每次落地彈一個音,長音跳得更高 |
| 15 | 碎石 | 球每撞牆就長大,碰到尖刺就碎成碎石堆在底部,尖刺跟著變長 |
| 16 | 收縮五角形 | 旋轉的五角形一直往內縮,兩顆球在裡面彈跳拖尾,縮到太小炸開 |
| 17 | 三色領土戰 | 三色領土各一顆球,撞到別色格子就染成自己的顏色 |
| 18 | 打碎環 | 球把同心磚環一塊塊打碎,整環清空就加速 |
| 19 | 火柴人電子雞 | 飽食 / 心情 / 精神隨真實時間下降,餵食、丟球(傾斜滾球讓牠追)、睡覺、清便便;搖久了頭暈;表情隨狀態變;狀態存 NVS、用 RTC 算離線時間 |
| 20 | 火柴人盪繩 | 吊著繩子在錨點間盪,點螢幕放手、手靠近錨點自動抓;掉地上重來 |
| 21 | 小恐龍 | Chrome 斷線小恐龍:點螢幕跳、按住下半部蹲,越跑越快,每 300 分日夜切換 |
| 22 | 壓板與 Seed | 壓板每隔幾秒壓下,壓到的球 xN 增殖把箱子塞滿;你是 Seed,傾斜移動、點螢幕跳,別被壓到 |
| 23 | 同色合併競賽 | 頂端不斷丟小球,同色碰到就合併變大,先長到門檻的顏色贏;點螢幕在手指處丟 3 顆 |
| 24 | 黑筆塗圓 | 白盤裡的球每撞牆就畫一條粗黑弦、變大、換色,大到塞滿就結束 |
| 25 | 每彈一次生一顆 | 無重力圓場,球撞到帶缺口的旋轉弧就多生一顆;傾斜控制環的轉速;5 秒沒創新高就結束,顯示最高球數 |
| 26 | 轉環引路 | 彈珠倒進三層帶缺口的同心弧環中心,A/C 轉環讓缺口對上 |
| 27 | 蹺蹺板 | 彈珠壓在蹺蹺板哪邊那邊就沉,點一端壓下去、A/C 全部壓向一邊 |
| 28 | 雙輪 | 屋頂把彈珠分到左右槳輪,按住 A / C 轉左 / 右輪把口袋裡的彈珠倒下去 |
| 29 | 尖刺碗 | 碗底有刺,傾斜推彈珠、A/C 轉碗把彈珠倒出去、別碰到刺(碰到就破) |

26 到 29 是彈珠系列(取自第四支影片):6 色彈珠輪流倒進場地,掉出底部就依顏色堆進右邊的管子累積,哪根先滿就全部清空重來,沒有輸贏。全部都是傾斜給左右重力、點螢幕推開彈珠。

有輸贏的遊戲(小恐龍、壓板與 Seed、電子雞的壽命)結束時顯示前 5 名排行,存 NVS。

6 到 18 取自另一支參考影片的段落。所有遊戲都吃傾斜(重力或方向偏向)與觸控(踢球、生東西或推開),各遊戲檔開頭的註解寫了具體互動。

## 操作

螢幕下方三個觸控鍵:

- 選單:A / C 或左右滑換遊戲,B 或點預覽進入;10 秒沒操作自動輪播;卡片下方顯示該遊戲進入過幾次(存 NVS)
- 遊戲內:A / C 是遊戲操作:有東西在轉的遊戲(色層擴張、井字、向心 / 逃脫加速、碎石、五角形、同色合併、每彈一次生一顆、轉環引路、蹺蹺板、雙輪、尖刺碗)用來轉它;小恐龍 A 跳 C 蹲;其他是往左 / 往右的虛擬傾斜。B 長按回選單、雙擊重置(短按不做事;B 只認鍵區正中 70 px,靠邊的算按 A / C 擦到)

## 建置

```
pio run -t upload
```

PlatformIO + Arduino framework,依賴 M5Unified(`platformio.ini`)。

搖晃:主迴圈算加速度大小偏離 1 g 的量給 `Ctx::shake`;彈珠搖一下散開,電子雞搖久了頭暈。

## 校正

`src/common.h` 頂部:`TILT_X` / `TILT_Y` 傾斜方向反了就翻號,`TILT_GAIN` 調靈敏度。

## 結構

- `src/main.cpp`:選單與主迴圈;新遊戲寫一個 `.h` 提供 `init / step / draw`,在 `games[]` 加一行
- `src/common.h`:畫布、Ctx、顏色、震動、音效合成、圓形場地反彈 / 點擊踢球 / 定速等共用函式
- `src/ringlib.h`:環系列共用(弧線、球與扇區碰撞、火花、脫落環片)
- `src/balls.h` `plinko.h` `expand.h` `ttt.h` `slicer.h` `gaprings.h`(6 與 13)`tri.h` `merge.h` `grow.h` `balloon.h` `split.h` `paint.h` `beat.h` `rubble.h` `penta.h` `war.h` `shatter.h` `pet.h` `swing.h` `dino.h` `seed.h` `colormerge.h` `inkring.h` `spawnring.h` `arcring.h` `seesaw.h` `wheels.h` `spikebowl.h`:各遊戲
- `src/marblelib.h`:彈珠系列共用(彈珠池、線段 / 圓 / 弧碰撞、子步物理、右側色管)
- `src/face.h`:火柴人的臉與表情(電子雞、盪繩共用);`src/ragdoll.h`:Verlet 布娃娃骨架(盪繩用)
